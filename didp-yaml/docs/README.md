# YAML-DyPDL Documentation

To check an existing candidate solution, start with the [validator quick start](../README.md#install-the-validator).
It includes validator-only installation and a complete example; no solver configuration or solver run is needed.

- [Validator Guide](./validator-guide.md): solution format, diagnostics, exit codes, cost comparison, and the Rust library API.
- [DyPDL Guide](./dypdl-guide.md): write the domain and problem files used by both validation and solving.
  - [Expression Guide](./expression-guide.md): syntax for model expressions.
- [Solver Guide](./solver-guide.md): for finding solutions with a didp-yaml solver.
